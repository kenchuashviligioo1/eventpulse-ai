# Changelog — შესრულებული სამუშაოების ისტორია

## [v0.1.0] - ეტაპი 1: პროექტის ბაზა

- შეიქმნა `eventpulse-ai` რეპოზიტორი.
- დაინსტალირდა საჭირო პაკეტები (`zustand`, `react-hook-form`, `yup`, `recharts`, `qrcode.react`, `html5-qrcode`).
- გაიმართა როუტინგი 4 ძირითადი მიმართულებისთვის (`/`, `/my-tickets`, `/sponsor`, `/scanner`).

## [v0.1.1] - ნავიგაციის ოპტიმიზაცია

- საჯარო `Navbar`-იდან ამოღებულ იქნა `/sponsor` და `/scanner` ბმულები; აღნიშნულ გვერდებზე წვდომა ხორციელდება მხოლოდ პირდაპირი URL მისამართით.

## [v0.2.1] - UX ოპტიმიზაცია მომხმარებლის მხარეს

- საჯარო ივენთის ბარათებიდან ამოღებულ იქნა შიდა AI ფასწარმოქმნის სლაიდერი და ფასის ზრდის ინდიკატორები; მომხმარებლისთვის ჩანს მხოლოდ საბოლოო ფასი და Smart Drop ფასდაკლება.
- AI კონტროლის პანელი გადანაწილდა ორგანიზატორის დახურულ მოდულში (ეტაპი 4).
