# EventPulse AI ⚡

AI-ზე დაფუძნებული ბილეთების დინამიკური ფასწარმოქმნისა და სპონსორების ROI ანალიტიკის პლატფორმა.

## ტექნოლოგიები (Tech Stack)

- **Frontend:** React (JavaScript), Vite, Tailwind CSS v4
- **State Management:** Zustand
- **Forms & Validation:** React Hook Form + Yup
- **Routing:** React Router DOM
- **Visuals & QR:** Recharts, Lucide React, QRCode.react, HTML5-QRCode

## გაშვება ლოკალურად

\`\`\`bash
npm install
npm run dev
\`\`\`
